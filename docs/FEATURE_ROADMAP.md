# FlowDeck — Asana Feature Roadmap

> Generated from full audit of FlowDeck vs Asana. Check off as implemented.

---

## 🔴 Tier 1 — High Priority

- [x] **1. Task Completion Checkbox (everywhere)** — Circle checkbox on every task in List, Board, Timeline, Sheet; click to complete with strikethrough animation
- [x] **2. Tags / Labels** — Add tags: string[] to Task, tag management (create/remove), color-coded tag pills, filter by tag across views
- [x] **3. Task Due Dates** — Separate dueDate from start+duration, overdue warnings (red/amber), Calendar shows due dates
- [x] **4. Comments & Activity Feed** — Add Comment type, comment thread in TaskDetailPanel, activity log with tabs
- [x] **5. My Tasks View** — New nav item + view showing tasks assigned to current user, sections: Today / Upcoming / Later / Overdue / Recently completed

## 🟠 Tier 2 — Medium-High Priority

- [ ] **6. Interactive Gantt Drag** — Drag bars left/right to change dates, drag bar edges to resize duration, drag between rows to reassign, drag to create dependencies

## 🟡 Tier 3 — Medium Priority

- [ ] **7. Sections Within Projects** — Section type, sectionId on tasks, collapsible sections, Board swimlanes, Timeline grouped bands
- [ ] **8. Custom Fields with Real Types** — Dropdown, Number, Date, Text, People custom fields; shown in Sheet columns and detail panel
- [x] **9. Drag-to-Reorder Tasks** — Drag tasks in List, Sheet (row reorder), and Board (within column + between columns reorder); persist custom order
- [x] **10. Quick Add (Everywhere)** — Press Enter / + button to add task inline in Board columns, Task list end, Sheet 'click to add' row; type name, press Enter to create
- [x] **11. Keyboard Shortcuts** — Tab/Shift+Tab indent/outdent, Enter quick-add, Backspace delete, Space toggle complete, 1-4 set priority, / focus search, ? show cheat sheet
- [ ] **12. Workload / Resource Management** — Time-based grid (weeks/months), team member rows, task blocks spanning duration, overallocation in red, capacity planning
- [x] **13. Dark Mode** — Full dark theme tokens, system preference detection, toggle in sidebar/settings

## 🟢 Tier 4 — Low Priority

- [ ] **14. Task Duplication** — ⋯ menu 'Duplicate task', optionally duplicate subtasks/attachments/comments, copy with '(copy)' suffix
- [ ] **15. Multi-Home Tasks** — Task in multiple projects, primary project concept, different project colors in different contexts
- [ ] **16. Followers / Watchers** — Add followers to task, heart button to follow/unfollow, followers list in detail panel, notification on changes
- [ ] **17. Milestones View** — Dedicated view showing all milestones, diamond markers on timeline, filter upcoming/past, milestone details with linked tasks
- [ ] **18. Project Templates** — Save project as template, create new project from template, includes task structure, custom fields, sections
- [ ] **19. Goals / OKRs** — Hierarchical goals (Company → Team → Individual), progress updates (On Track/At Risk/Off Track), link goals to projects/tasks
- [ ] **20. Forms / Request Forms** — Create forms for task intake, custom fields on form, submissions auto-create tasks, bug reports / feature requests
- [ ] **21. Rules / Automation** — Trigger→action rules (e.g. 'When task moves to Done, notify owner'), simple no-code automation builder
- [ ] **22. Approvals** — 'Waiting for approval' status, assign approver, approve/reject buttons, approval history in detail panel
- [ ] **23. Project Status Updates** — Periodic project status (green/yellow/red), written update with highlights, shared with stakeholders
